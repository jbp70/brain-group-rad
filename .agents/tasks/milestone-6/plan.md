## 0. Pinned conventions (single source; implement exactly)

| Item | Convention |
|---|---|
| Field units | Displacements and velocities are in **voxel-index units of the level they live at** (design 2). mm = voxels × `P.LEVEL_SPACING[level]`. |
| Grid / center | Voxel index p; world (p − (n−1)/2)·s (unchanged, `models.layers.index_grid`/`world_grid`). Fields act on voxel indices directly, so the center does not enter them. |
| Pull warps | `warp(vol, u)(x) = vol(x + u(x))` for every output voxel x. φ(x) = x + u(x) maps central-space points to image-i (affine-central) points (design 2: φ_i central → image i). Warped image = I_i ∘ φ_i. |
| Composition | `compose(u_a, u_b)` = displacement of φ_a ∘ φ_b (φ_b applied FIRST): `u_b + warp_field(u_a, u_b)`. |
| Field resampling boundary | Fields are resampled with **border** clamping (sample coordinates clipped to [0, n−1] per axis = edge replication), so a constant field stays exactly constant. Images and one-hot labels use **zero** fill (the existing `transform_image` semantics: soft fall-off over the last voxel). |
| SVF | v_i from the SVF head, level voxels, central space. **Centering:** v_i ← v_i − mean_j v_j at every voxel (over the group axis 0, N dynamic). **Exp:** scaling and squaring, T steps (default 7): u ← v / 2^T, then T times u ← compose(u, u). T = 0 returns v. **Inverse:** exp(−v_i), never a numerical inversion. |
| Pairwise map | Image j coords → image i coords: Ψ_i ∘ Ψ_j⁻¹; with A = I: φ_i ∘ φ_j⁻¹, displacement `compose(u_i, u_inv_j)`. onehot_i warped into j's space = `warp(onehot_i, compose(u_i, u_inv_j))`, compared with onehot_j. One label interpolation per pair. |
| Cascade (milestone 8 hook) | φ^(k) = φ^(k−1) ∘ exp(v^(k)) → `compose(up(u_prev), u_k)`; φ^(k)⁻¹ = exp(−v^(k)) ∘ φ^(k−1)⁻¹ → `compose(u_inv_k, up(u_inv_prev))`, with `up` = `upsample_displacement` (trilinear ×2, values ×2). Only the single-level path is used in milestone 6. |
| Trilinear ×2 | World-consistent "half-pixel" semantics: coarse voxel q sits at fine coordinate 2q + 0.5, so fine voxel p samples coarse coordinate (p − 0.5)/2. Per axis: out[2k] = 0.75 x[k] + 0.25 x[k−1], out[2k+1] = 0.75 x[k] + 0.25 x[k+1], edge-replicated (x[−1] := x[0], x[n] := x[n−1]). Equals `scipy.ndimage.map_coordinates(x, (p−0.5)/2, order=1, mode='nearest')` exactly, and `scipy.ndimage.zoom(x, 2, order=1, mode='nearest', grid_mode=True)` (scipy ≥ 1.6). It is NOT align_corners (scipy < 1.6 `zoom` default). Same as tf.image bilinear `half_pixel_centers=True`. |
| Displacement upsampling | `upsample_displacement(u) = 2 · upsample_trilinear2x(u)`: fine p ↔ coarse c = (p − 0.5)/2, mapped to 2(c + u) + 0.5 = p + 2u. Exact for affine-like fields away from the border. |
| Jacobian | J = det(I + ∇u), central differences, **interior voxels only**: output `[N, X−2, Y−2, Z−2]` (equal to `np.gradient` on the interior). Folding fraction = mean(J ≤ 0). |
| Dtypes | Grids, fields, integration, losses in float32 (float64 if the field is float64); float16 inputs are cast to float32; never float16 grids. The SVF head is a float32 layer. One-hot labels float32 (fp32 default: level-4 one-hot is 8.2 MB per image, negligible; an fp16 option is not added). |
| None-grad filtering | All three train steps keep the m5 static filter `[(g, v) for g, v in zip(grads, tvars) if g is not None]` at trace time. Rigid steps: scale/shear head and the whole deform decoder get None. Affine steps: deform decoder gets None. Deform steps: the whole linear decoder (reductions, dense, heads, head_norm_act) gets None. The ONE optimizer is built on ALL trainable variables in `Trainer.__init__` (as in m5), so no step creates variables or retraces. BN statistics of a part that did not run are untouched. |

## 3. Gaps and assumptions

- Warm-starting a deform model from a linear-only checkpoint (milestone 7) is NOT in scope: `load_model_weights` will refuse because `deform_decoder` differs. Note it in the report as the milestone-7 follow-up (allow `deform_decoder` to differ and assert only encoder + linear variables).
- Residual-affine range flags are not exposed (design 3.2 values from `params.DEFAULT_DEFORM_RESIDUAL_RANGES`); `LinearDataModule(deform_ranges=...)` allows overrides in code.
- N = 32 deform steps at level 4 may not fit 48 GB with pairs (≈99 pair warps at p_pdice 0.1); `--deform-group-size` exists for that. Decide from the memory numbers.
- `tf.recompute_grad` around BN layers updates moving statistics twice per step; documented, default off.
- Absent labels are excluded from soft and hard Dice means (otherwise a synthetic phantom with 8 of 18 labels would report inflated Dice).
