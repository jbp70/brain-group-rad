# Level-2 training with a frozen level-4 cascade stage (milestone 8)

The change trains level 2 (80×112×96, 2 mm) as the second stage of a two-stage cascade. A frozen level-4 `GroupRegLevelModel` (`models/cascade.py::FrozenStage`) runs on the 2×2×2-pooled group in eval mode, outside the tape, under a float32 policy and behind `stop_gradient`. The trainable level-2 model starts from a verbatim copy of the same checkpoint and predicts a residual. For linear tasks the composition is `Center(R_raw · A4)`; for deform it is `compose_cascade(up(u4), up(u4⁻¹), u2, u2⁻¹)`. Around it the change adds forward-only BN recalibration with exact per-layer averaging, level skipping (default 0), cascade validation with cached frozen-stage baselines, provenance and fingerprint checks on resume, checker extensions with the C4 grad-balance verdict, a level-2 memory script, two SLURM recipes and the synthseg level-2 export. Every new path is gated at trace time. The level-4 goldens are recorded at max |diff| 0, and the full suite recorded 381 OK (4 skips).

Watch for: no blocking issues. Four minor items: a doc gap about Grappler in the T6 identity test (confirmed), the `S_rel_diff_vs_level4` null scope differing from the design (confirmed), the checker's frozen-baseline check covering only the un-G sets (confirmed), and a possible stale-layer false positive in `recalibrate_bn` for single-task ratios (possible).

**Verdict**: APPROVED

## High-level view

Gating holds. In `runtime/run.py`, the non-cascade step bodies only rename the model input (`x_in = batch["images"]`), so the tensor passed is the same. The extra `skip` TensorSpec exists only in cascade signatures. `train_step` calls the non-cascade step exactly as before. `_deform_errors(chunk=None)` resolves to the old literal 16, and the per-task timing and skip keys are logged only with a cascade. The parser restricts `--cascade-from` to `--level 2`, so level-4 runs never build a `FrozenStage`. The recorded goldens (`[golden] max |diff| 0`, `[golden deform] max |diff| 0`) agree with this reading of the diff.

The composition matches the design. The frozen outputs are computed before the tape and wrapped in `stop_gradient`, and the frozen variables never reach `O.build_optimizer`. Pre-warps use the conventions (pull with A⁻¹; `warp(x, U)`). Losses act on the composed A and the composed u, applied to the original batch images and one-hot. `diag_u_res_max_vox` is the only extra deform diagnostic.

BN recalibration follows the v5 rules. The parser rejects K > 0 without `--cascade-from`, with the exact message. `recalibrate_bn` raises on a non-cascade trainer. main.py runs it only when `cascade_on and not cascade_resume and K > 0`. Each layer gets momentum `c/(c+1)` per eager forward, and each layer's own momentum is restored in `finally`. On resume the freeze comes from the saved `bn_recalibration.freeze`, followed by `rebuild_steps()`.

Resume and provenance follow NIT 4. `cascade_resume` is decided once, before any model is built. A resume never reads the source. It fails hard when `restore_last()` returns False, checks the fingerprint at rel 1e-12, and copies `init_weights`, `cascade` and `bn_recalibration` over verbatim.

The checker's grad-balance rule is the ratio of medians over records with window-end step ≥ 50, with KEEP iff both ratios fall in [0.1, 10]. It is INFO only. Both SLURM scripts follow the cluster rules (rerun locally: `bash -n` OK, no `entre`, stub tests OK).

### Level skipping identity depends on Grappler

T6 proves the `tf.where` path is the identity when `skip` is false, but only with Grappler off. With Grappler on, the presence of the `SelectV2` ops changes the rewrites of the deform step (8.6e-8 after one step, amplified by Adam). This is harmless for milestone 8, where p=0 builds no skip ops. It does mean a p>0 run fed all-false skips is not bitwise equal to a p=0 run in production. Design §16 T6 still states a strict max |diff| 0 without the condition.

### BN recalibration stale-layer check

The stale check flags any recalibrated layer whose non-trainable BN variables are bitwise unchanged. Because `layers` is the union over every task's parts, a layer reachable only through a task that has no slots would be flagged. Under the three-task recipe every part is used, so this matters only for single-task ratios (issue 4).

### Resume and provenance

`cascade_resume = bool(args.resume) and peek_last_step(ckpt/last) > 0` is decided once, before the data and model are built. A fresh run that crashed before its first checkpoint therefore re-reads the source and recalibrates again, as the design states. On resume `init_info` stays None, so the existing `elif args.resume and latest_last` branch restores. The new block then raises if nothing was restored, checks the fingerprint, and re-freezes from the saved record. The second `write_config` after recalibration reuses `config_extra`, so `cascade` and `init_weights` survive the rewrite.

`S_rel_diff_vs_level4` is computed only when `not args.overfit_one_group` (issue 2). The DALI-path computation (`brain_S_matrix(4, <data>/template)` against the run's level-2 S) has no local test. Cluster job (a) and the smoke run will exercise it first. A failure there (missing `template_mask_4.npy`) would abort a fresh run before training, with a traceback.

### Checker and SLURM

`grad_balance` filters on `r["step"] >= from_step`, takes medians of finite `_eff` values, returns UNDECIDED on a missing or zero deform median, and is wired as INFO. `_check_cascade` validates provenance (`source_level == 4`, integer step, `n_vars > 0`, `via == "cascade"`) and requires final-step frozen keys per trained task name (issue 3 for `_g`). Both scripts have `-A qtim`, `-p rtx8000`, `--gpus=1`, `-N 1`, `--ntasks-per-node=1`, `--cpus-per-task=3`, `--mem=64G`, `--time`, logs under `.../GroupwiseReg/logs`, the sif path, `TMPDIR="$SCRATCH_ROOT/$JOB_ID"` (default `/scratch`), and `</dev/null` on every singularity call. The `CASCADE_FROM` guard runs only for fresh runs.
